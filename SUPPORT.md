# Getting support

## Community support
For most cases, support is given by the community to the community.
To get support you can:
1. Start a [discussion](https://github.com/IBM/mcp-context-forge/discussions)
2. Create an [issue](https://github.com/IBM/mcp-context-forge/issues)
3. Or report a security issue (Please do not create a public issue with security details): [Create a security issue](SECURITY.md)

## For additional support requirements
Please contact IBM for a support offering related to this open source project
